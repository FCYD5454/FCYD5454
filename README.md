# Hi, I'm FCY

I'm a Computer Science student in Hong Kong and an independent game developer. I'm currently building a Steam game.

## What I'm working on

- **TimeStop: Dead City** — my current Steam project, built in Unity 6 / C# around time-stop mechanics.
- **Campus Rebirth** — a story-driven campus life simulation in Godot 4.7 / GDScript, with data-driven lessons, events and localization.
- **AI-assisted development and media.** I use AI tools to prototype ideas, troubleshoot code, and experiment with game art and animation. I test the results in Unity to see what actually works in the game.

## Projects

### TimeStop: Dead City — in development

Unity 6 · C# · Steam

A time-stop game set in a dead city, with a multi-scene prologue, explorable interiors and a 2D/3D mixed presentation.

### Campus Rebirth — in development

Godot 4.7 · GDScript · Data-driven · Localization

A four-year campus life simulation focused on a Computer Science storyline. Lessons, events and UI are JSON-driven, with per-locale text overlays.
